# Notice Tracker

Single-page web app generated from the 25 column headers in `GUI-Trial-App-1.xlsx`.

- Open `index.html` in a browser. No build step.
- Add, edit and delete notices; search, filter and sort the ledger.
- Days Remaining and Deadline Status are calculated from Deadline. Last Sync is set on save.
- Import a filled copy of the Excel file; export to .xlsx or copy as CSV.
- Data is stored in the browser (localStorage).
- `app.html` is the same app as a fragment for hosted-artifact publishing.
